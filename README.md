# Jake Reisdorff

Full-stack TypeScript developer in Omaha, Nebraska. I build web apps with React, Next.js, and Remix, and I keep coming back to audio: synthesis, tuning theory, and tools for making music. I also shoot and edit video. I worked fully remote from 2020 to 2024 and I'm open to remote roles.

## Featured projects

| Project | What it is | Built with |
|---|---|---|
| [RemoteTelescope](https://github.com/jreisdorff/RemoteTelescope) | Speculative sci-fi app. Observe planets as they were when their light left them, record claims about their present, and verify them against later observations. Spec-first, 17 tests, clean production build. | Next.js 15, React Three Fiber, SQLite, Zod, Vitest |
| [Binaural Beat Generator](https://github.com/jreisdorff/BinauralBeatGenerator) | Renders binaural-beat WAVs and a MIDI reconstruction of an Old Babylonian retuning cycle, with a Next.js site to listen and explore. | TypeScript, Web Audio, Next.js, Framer Motion |
| [Poker World](https://github.com/jreisdorff/poker-world) | Real-time three-player Texas Hold'em in the browser: websocket state sync, a full hand state machine, Docker and Fly.io config, and a CI pipeline. | Remix, Socket.IO, Prisma, Tailwind, Cypress |
| [Sexagesimal Counter](https://github.com/jreisdorff/sexagesimal-counter-vhdl) | A base-60 counter as a simulated chip, driven from VHDL testbenches, a glyph-script generator, and bare-metal RISC-V under QEMU. | VHDL, GHDL, Python, RISC-V |
